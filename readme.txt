Embed Funeral Atlas Price Index, Market Counter and Funeral Cost Calculator.

== Description ==
Funeral Atlas Widgets adds the shortcode [funeral_atlas_widget].

Examples:
[funeral_atlas_widget mode="index"]
[funeral_atlas_widget mode="counter"]
[funeral_atlas_widget mode="calculator"]

== External service ==
This plugin displays live Funeral Atlas widgets from https://funeral-atlas.art/ inside an iframe.
The external service provides the market data and calculator interface shown by the widget.

== Installation ==
1. Upload and activate the plugin.
2. Add a Funeral Atlas shortcode to any page or post.
